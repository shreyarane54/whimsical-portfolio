# ✦ Whimsical Portfolio

A playful, story-driven portfolio landing page for a freelance web designer & developer.

Instead of following a traditional portfolio layout, this project creates a small illustrated world where visitors can explore the designer's work, skills, process and contact information.

> A little corner of the internet, made with curiosity. ✦

---

## ✦ About the Project

This is a creative **portfolio landing page concept** designed around the idea of:

> **“A little corner of the internet.”**

The website combines whimsical illustrations, editorial typography, playful interactions and smooth animations to create a memorable browsing experience.

The visual journey moves through:

**Desk → Introduction → Little House → Toolbox → Selected Work → Process → Mailbox**

---

## ✦ Features

- Whimsical editorial-inspired design
- Handcrafted CSS illustrations
- Custom cursor interaction
- Smooth scrolling
- GSAP animations
- GSAP ScrollTrigger
- Parallax effects
- Scroll-triggered reveals
- Interactive skill cards
- Project showcase
- Hover interactions
- Floating decorative elements
- Paper/grain texture
- Responsive design
- Mobile-friendly layout

---

## ✦ Tech Stack

- HTML5
- CSS3
- JavaScript
- GSAP
- GSAP ScrollTrigger
- Lenis
- Google Fonts

No frontend framework is required.

The landing page is built using vanilla HTML, CSS and JavaScript.

## ✦ Sections

### 01 — Hero

The experience begins inside a small illustrated workspace.

It includes:

- Personal introduction
- Designer/developer identity
- CTA
- Laptop
- Coffee
- Plant
- Character
- Clouds
- Stars

---

### 02 — Introduction

A short introduction presenting the creative approach behind the portfolio.

> I'm a designer who likes to code.

---

### 03 — About

The About section is represented by a small illustrated house.

The house acts as a visual metaphor for the person behind the website.

---

### 04 — Toolbox

A playful skills section featuring:

- HTML
- CSS
- JavaScript
- GSAP
- React
- UI / UX

The cards use subtle rotations, hover effects and animations.

---

### 05 — Selected Work

A visual showcase of selected projects.

Example projects include:

- Astromasster
- Care Lifting
- Creative Studio

The project visuals can be replaced with real project screenshots.

---

### 06 — Process

The creative process is presented as a small journey:

Discover
   ↓
Design
   ↓
Build
   ↓
Launch

07 — Contact

The final section uses a whimsical mailbox concept.

The visitor is invited to:

Have an idea? Leave me a note.

The CTA currently uses an email link and can later be connected to a contact form.
